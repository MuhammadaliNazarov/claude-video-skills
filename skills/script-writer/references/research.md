# Research notes (2026-10-13)

## What Instagram ranks (confirmed vs claimed)

- **Confirmed by Adam Mosseri (Jan 2025):** the three signals that matter most are **watch time**, **likes per reach**
  and **sends per reach**. Likes weigh slightly more for followers (connected content); **sends weigh more for reaching
  non-followers**, so "send this to…" moments drive discovery. Watch time counts seconds watched as well as the share of
  the video, so longer videos are not punished if they hold.
- **Claimed by marketing blogs, unverified:** DM sends weigh 3-5x likes; a repost penalty from April 2026; exact
  length caps. Treat as hypotheses.
- **Implication for scripts:** write for completion (pay the hook late, re-hook), for sends (identity, "this is so
  you", useful lists), and for saves (lists, cheat sheets, "read caption").

## Pacing numbers worth using (from guides, test them)

- Hook by ~1 s, promise of the payoff by ~3 s; opening hook ~8-12 spoken words.
- A noticeable beat (new visual, twist, re-hook) every ~15-20 s on longer videos; the Kallaway Reel changes something
  every 1-2 s.
- Kallaway speaks at ~242 words/min with the median gap between words 0.04 s (measured).
- Write 3-6 hook variants per idea and test.

## Frameworks found

- **But / Therefore** (Parker & Stone): every beat joined by "but" or "therefore", never "and then".
- **Hook → story → payoff**; **hook → setup → body → close** (most hooks fail because the body doesn't match the tease);
  **hook → problem → solution → CTA**.
- **Kallaway:** script = context and conflict, set-up then re-hook, not hook-body-conclusion; hook moves = context
  lean-in, scroll-stop interjection, contrarian snapback; 4 hook components that must align (text, spoken, visual,
  audio); short-form feeds long-form where conversion happens.
- **Promise → Proof → Plan** (attributed to Hormozi; proof can come first for cold audiences).
- **Pattern interrupts:** an unexpected movement or object in frame one; POV framing suits headphones-on Reels viewing.
- **Open loops:** open early, close later, don't nest too many.
