# Script writer

Writes short-form scripts that people watch to the end, send to a friend and follow for. Built from proven short-form
formats, a frame-by-frame breakdown of a Kallaway reference Reel, and current research on hooks and Instagram ranking. Pairs with the `video-editor` skill: every script ends
with notes that editor can execute (caption style, B-roll list, music, cut pace).

## Read before writing

| File | What it gives you | Read when |
|---|---|---|
| `creator-profile.md` | who the creator is: the default real story, niche, platform | every script |
| `references/storytelling.md` | the story structures and the rules that make them work | any story, transformation, opinion or explainer |
| `references/hooks.md` | hook rules, the three hook layers, 60+ templates sorted by mechanism | every script (hooks are written last and tested) |
| `references/research.md` | what Instagram ranks, pacing numbers, sources | strategy questions, length, CTA choice |
| `references/sfx.md` | the 75-sound library mapped to beats (hook, flashback, explosion, win, CTA…) with per-format budgets | every script: fill the SFX column |
| `references/shotlist.md` | shot vocabulary, the shot-list columns, B-roll rules, filming order | every script: the draft shot list |
| `references/talking-head-setup.md` | background + lighting for the dorm room or outside, with fixes | every script with him on camera |
| `templates/script.md` | the exact output layout | every delivery |

Optional raw material: put your own format notes or reference write-ups in `references/` (e.g. a
.docx/.mp4, `combined/*.md` write-ups, `combined/transcripts.md`) and `references/ref01/` (the Kallaway Reel).

## The workflow

1. **Intake (ask only what is missing, max 4 questions in one message):** who is the viewer (one specific person),
   what do they get (laugh, cry, learn, feel seen), the creator's real story or proof, the goal (followers, comments,
   DMs/lead magnet, sales), talking or text-on-screen, length. Read `creator-profile.md` (fill it in once:
   who you are, where you're from, what you're building, where you post) and use it as the default "real story"; never
   invent achievements, numbers or quotes.
1b. **Mine the story (personal formats).** Pick the L.I.F.E. pillar (Love, Identity, Fitness, Earnings) and ask
   "why?" three times (Safe → Real → Raw, storytelling.md §11). Write from the Raw layer; if he hasn't given it, ask.
2. **Pick the format.** Match the goal to a format family (Advice, Opinion, Relatable, Storytelling, Easy-to-use; storytelling.md and hooks.md). Prefer a proven format
   and change as few variables as possible: keep the hook wording and structure, swap in the creator's niche and story.
3. **Write the spine before the words.** One sentence: "[Viewer] will watch because [curiosity/stakes] and leave with
   [payoff]." Then the beats, each joined by **but** or **therefore**, never "and then".
4. **Write the body, then the hook.** Draft 5 hook options across different mechanisms (hooks.md), each with its text
   hook, spoken line and opening visual aligned. Recommend one and say why.
5. **Tighten.** Cut every line that does not raise stakes, answer the question, or set up the next beat. Spoken: 150 to
   250 words a minute, sentences under ~15 words, one idea per line, "you" language. Text-on-screen: each line readable in
   the time it is on screen (read it aloud; the cut comes when you finish).
5b. **Make it live.** At the key moment (low point or explosion) add one or two sensory details and switch to present
   tense; before the CTA, state the meaning in one line ("The reason I'm telling you this…"). Check the dopamine ladder:
   first frame stimulates (level 1), hook opens a loop (2), a head fake (3), a non-obvious payoff (4), his personality
   on screen (5).
6. **Sound pass.** Fill the SFX column from `references/sfx.md`: pick per beat, name the exact word it lands on,
   stay inside the format's budget, leave `—` where silence is stronger.
6b. **Shot list + setup.** Draft the shot list from the script (`references/shotlist.md`): 1-3 B-roll shots per
   line, close-ups ≥ a third, ordered by location for filming, planned cut types, room tone. Recommend the talking-head
   spot and light (`references/talking-head-setup.md`); if he sends a photo of the spot, check it and say what to move.
7. **Deliver** in `templates/script.md` layout, then run the scorecard below and fix anything under 2.

## Non-negotiables

- **The first second does the work:** a moving image + a line that creates a gap (curiosity, stakes, contradiction,
  identity call-out). No greetings, no "so today", no logo.
- **Every promise is paid.** The body delivers exactly what the hook teased; the payoff lands before the CTA.
- **Specific beats vague:** ages, numbers, times, places, names, the exact words someone said ("You need jaw surgery").
- **Vulnerability + proof:** an honest low point, then evidence it is true (photos, dates, screen recordings, results).
- **One video, one message, one viewer.** Remove side stories ("remove noises").
- **B-roll shows, it does not decorate:** every line has a shot that proves or mirrors it (the action or the emotion).
- **Re-hook every 15 to 20 s** on longer scripts: a new question, a twist, "but here's the part nobody tells you".
- **CTA matches the payoff:** follow for the next part (open loop), comment a keyword for the resource, send to the
  person it describes, save for later. One CTA.
- **Never fabricate** results, testimonials, numbers or stories for the user. Ask, or mark `[fill: your number]`.

## Scorecard (rate 0 to 3, fix anything under 2)

| Check | Question |
|---|---|
| Hook | Would a stranger stop in 1 s, muted? Is there a gap they need closed? |
| Alignment | Do the text hook, spoken line and first visual say the same thing? |
| Stakes | Is something at risk or wanted, and does the viewer care within 5 s? |
| Flow | Is every beat joined by but/therefore? No "and then" stretches? |
| Specificity | Real numbers, ages, names, dialogue? |
| Payoff | Is the hook's promise paid clearly, before the CTA? |
| Shareability | Would someone send it to a friend ("this is so you")? |
| Proof | Is there visual evidence for every claim? |
| Raw | Is it written from the Raw layer (a truth he wouldn't normally say), not the Safe one? |
| Meaning | Is the "why I'm telling you this" said in one line before the CTA? |
| Ladder | First frame stimulates (motion/colour/contrast) and his face appears at least once? |
| CTA | One clear ask that fits the payoff? |

## Keeping it the user's

"Save this to the skill" after feedback: write it as one rule in the file it belongs to (a hook rule → hooks.md, a
structure rule → storytelling.md, a new format the user liked → `references/formats.md` (create it) with its source link).
Replace a rule a new one contradicts. When a script performs well, add it to `references/winners.md` (create it) with the
numbers the user reports.
